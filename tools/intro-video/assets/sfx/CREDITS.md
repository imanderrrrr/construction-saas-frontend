# Sound effects

Two sources, both real recordings:

**Pixabay Content License** (commercial use and modification allowed, no attribution; they may
travel inside a video, not be published on their own) — from the media-use library:
`impact-bass-1`, `impact-bass-2`, `pop`, `whoosh-short`, `whoosh-cinematic`, `sparkle`.

**HeyGen sound-effects catalog**, found with `heygen audio sounds list --type sound_effects` and
downloaded with the account owner's OAuth session — `rattle-assembly`, `clink`, `strike-ring`,
`thud-heavy`, `thud-muffled`, `thud-room`, `clunk-scrape`, `rip-tape`, `rattle-pieces`.
**Check HeyGen's terms for commercial use outside HeyGen's own videos** before relying on these;
if they do not cover it, replace the files (same names) and re-run `npm run render`.

| File | Used for |
|---|---|
| `impact-bass-1` | the black foundation of the mark fills in |
| `pop` | the orange A fills |
| `whoosh-short` | the mark slides left; the name rises (slower, softer) |
| `whoosh-cinematic` | builds under the hold and crests on the whip-pan to the site |
| `rattle-assembly` | the scaffold and the crane go up |
| `clink`, `strike-ring` | the scaffold's couplers snap on |
| `thud-heavy`, `thud-muffled`, `thud-room` | each course of BuildTrack is laid |
| `impact-bass-2`, `clunk-scrape`, `sparkle` | the crane sets the orange stroke: swell, contact, sparks |
| `rip-tape` | the site tape is cut |
| `rattle-pieces` | the scaffold comes down |
